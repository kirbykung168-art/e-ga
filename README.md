# e-ga / อีกา

Single-page tribute site for **e-ga** (อีกา) — the regional-Thai restaurant group inside *It's Happened to be a Closet*, with three Bangkok branches (Song Wat · Sathorn 12 · Sukhumvit 23) and sister concept **e-ga Luv Seafood**.

> "กินเช้า Local Breakfast จากทั่วไทย" — breakfasts from across Thailand.

## Brand notes

- Name spelling lock: **e-ga** (lower-case, hyphenated). Never "Ega" mid-page.
- Thai: อีกา / อี_กา / อีกา_อิสแฮพเพ่น
- Group: It's Happened to be a Closet (founder Siriwan Tharananithikul)
- IG: [@ega_bangkok](https://instagram.com/ega_bangkok) · FB: [/egabangkok](https://facebook.com/egabangkok) · LINE OA reservations
- Vibe: witty, ink-dark, regional-Thai editorial
